# Fonts

Self-hosted so pages do not wait on a third-party font server.

- `mona-sans-*.woff2`: Mona Sans by GitHub, SIL Open Font License 1.1 (variable: weight 300 to 500, width 100% to 125%).
- `geist-*.woff2`: Geist by Vercel, SIL Open Font License 1.1 (variable: weight 400 to 500).

Each family comes as a Latin file and a Latin Extended file; browsers download the extended one only if a page uses those characters.
